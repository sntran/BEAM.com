# The claims of docs/SANDBOX.md, one claim on each line. tests/run.sh and
# tests/run.ps1 run each line: the program tests/programs/sandbox_check.erl
# (built with no permissions) with BEAM_COM_ALLOW, and its action. Its
# output must have the line "NAME: RESULT" (NAME is the first word of the
# action, and "run PROGRAM" for run), with the result of this system.
#
# The fields, separated by " | ":
#
#   claim | BEAM_COM_ALLOW | action | linux | linux-no-landlock | darwin-arm64 | windows | openbsd | other
#
# - linux-no-landlock: Linux with a kernel that has no Landlock. There
#   beam.com checks the paths in the calls of the C library, as on Windows.
#   tests/run.sh uses this column when beam.com prints the warning "the
#   kernel has no Landlock".
# - other: macOS x86_64, FreeBSD and NetBSD, which have no sandbox.
# - A result is a pattern of grep (and of PowerShell), for example "ok",
#   "error eacces" or "error e[a-z]*". "-": this line does not apply on
#   this system.
# - $IN is a directory of the rules, with a.txt, sub/b.txt and d/. $OUT
#   is a directory outside the rules, with a.txt and d/. $SELF is the file
#   of the program. Each line gets new directories.
# - $SOCK is a Unix socket that listens, in $IN (a listener of python3
#   in tests/run.sh). Only tests/run.sh has it, and it skips the lines
#   with $SOCK when python3 is not there.
#
# Caution: a change of docs/SANDBOX.md needs a change of these lines, and
# a line that fails is a difference between the document and the program.
# Change the program, or change the document and the line. Do not change
# only the line.
