A build URL: GET /beam.com?nifs+=rusty_csv gives the default NIFs and these NIFs. The query nifs+= is the field nifs , with a space, so the pattern of the body tells it from nifs=. The answer is the file beam-u.plus.NAMES.com, with the names in the sequence of sort. When the file is not there yet, beam.com/u says "not yet", and cat asks again (section 8.10 of the specification).
