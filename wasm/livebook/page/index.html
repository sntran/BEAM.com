The documentation of beam.com is a set of notebooks. Livebook, Phoenix, Elixir and Erlang/OTP run in this page, in BEAM compiled to WebAssembly, and no server runs your code. The first visit loads about 30 MB; the next visits start from a snapshot. The notebooks stay in the memory of this tab: download a notebook to keep it. To read the documentation without Livebook, open the static pages.
